# Character still creation template

## Phase A — Generate ONE clean identity anchor per character

**Reference creation prompt:**
> Create ONE character only. Use [paste CHARACTER primary identity paragraph]. One upright mid-chest portrait, facing lens at eye level, both eyes visible, modest natural expression that fits the role. Show facial skin texture, pores, asymmetry, age marks, believable hair and fabric, fine drawn ink lines and directional crosshatching. Apply [GLOBAL ART DIRECTION]. Plain parchment backdrop or subdued accurate environment. No grids, panels, labels, watermarks or second characters. Make largest supported native resolution, ideally 2K–4K. Vertical 9:16 or 4:5.

1. Review face, costume, era and mood before approving the portrait.
2. Save portrait with the character ID: `CHR-XYZ_front_v1.png`.
3. Generate left/right 3/4, profiles, rear etc. **using the approved portrait as reference where supported**.
4. Reject faces which drift (nose, jaw, eye spacing, age), inconsistent headdress, wrong class/era.
5. For each new character, repeat the process; one portrait cannot serve as a universal reference for a whole class.

## Phase B — Video
Prompt structure: `CHARACTER IDENTITY` + `SETTING AND ERA` + `MOTIVATION` + `EXPRESSION` + `ACTION` + `CAMERA` + `MOVEMENT` + `STYLE/CONTINUITY` + `DURATION/ASPECT`.
Do not ask one generator to produce a 60-second action scene with 15 actors in one pass. Build separate 3–6 second shots and assemble them on the timeline.
